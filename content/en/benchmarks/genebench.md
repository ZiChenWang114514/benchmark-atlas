# GeneBench / GeneBench Pro

> Benchmark Constitution | In-depth verification: 2026-11-07. The access date follows the fixed collection date, and run times are listed separately. Unverified is not the same as Not disclosed; conflicting sources are retained side by side.

GeneBench and GeneBench-Pro test continuous judgment in quantitative genomic analysis, rather than multiple-choice questions of biological knowledge. The earlier record relied only on model release notes and omitted the paper and the open cases; after that gap was filled, a specific correction is made: the tasks are based on patterns of real research, but the underlying evaluation data are constructed simulations.

## Design goals

**测量能力**：Long-horizon end-to-end analysis in genomics and quantitative biology: planning, quality control, modeling, and correction, yielding decision-relevant answers.

Sources: [1](https://openai.com/index/introducing-new-capabilities-to-gpt-rosalind/) (accessed 2026-11-07 )

**相对既有评测的缺口**：It tests whether an estimand, quality control, and model selection can be updated from a diagnostic signal, and whether those changes are carried through to the final decision, beyond retrieval of biological knowledge, a routine analysis pipeline, or an isolated step.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

## Construction

**题目来源**：This corrects the old dossier's summary of “real scientific data.” Real-world analysis patterns are induced from the literature and from internal experts, but GeneBench and Pro use constructed simulated data, controlling the full causal and generative process in order to obtain identifiable numeric answers. This is not a direct reuse of historical real cohorts.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**出题与研究背景**：GeneBench is signed by Jeremy Li (OpenAI/Herasight) and Andrew Ho (OpenAI); the Pro reviewers include graduate students, postdoctoral researchers, industry scientists, and professors.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**审核流程**：The original version received an independent review of scientific validity, methodological soundness, and whether the target is identifiable; of the 129 Pro questions, 82 were sent to external domain experts for review, and the feedback was used for revision; not all 129 questions have been externally reviewed.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**质量控制**：Numerical tolerance is kept for reasonable perturbations of the analysis, and ablations are used to verify that an incorrect analysis must fail; multi-turn trial runs of frontier models and audits of the full trajectory check information leakage, mismatch between the prompt and the grader, and unintended shortcuts.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**去污染与泄漏边界**：Well-known cases from textbooks and papers are not copied; new data are synthesized, and leakage and shortcuts are audited; the 10 public cases include ground truth and tolerances, the official source states explicitly that they are for reproduction and not a hidden-answer leaderboard, and that package cannot be used to measure generalization in the absence of contamination.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

## Data format

**规模与口径**：The original GeneBench: 103 items of evaluation and 10 domains. GeneBench-Pro: 129 questions, 10 domains, and 21 subdomains. 10 cases are public. There is also a plan to provide 50 questions to Artificial Analysis. The plan is not described as an independent run that has already been carried out.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 ) ; [3](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**任务类型**：Multi-stage scientific data analysis in an isolated workspace, outputting the JSON numeric or decision fields named by the question and a short rationale; this is not five-choice Genome-Bench question answering.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**模态**：科学数据；代码；文本分析

Sources: [1](https://openai.com/index/introducing-new-capabilities-to-gpt-rosalind/) (accessed 2026-11-07 )

**语言**：The public GeneBench-Pro card is labeled en; the data-analysis tools include Python and PLINK 2.0, among others. The language of a tool cannot be treated as coverage of natural language.

Sources: [1](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**难度**：Each question in the original version contains 3–13 substantive points of inferential decision, with a median of 6; external reviewers for Pro estimate that a typical question takes an expert 20–40 hours. That estimate is not a measured human completion time.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

**公开与隐藏划分**：Pro makes public 10 representative cases, including the task, the simulated files, ground_truth, the grader contract, and the reference scripts; the official source also announces 50 questions intended for AA. Whether assets that are Not disclosed can be obtained is not inferred from this. The public package is not a hidden test set.

Sources: [1](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 )

## Evaluation

**指标**：The main metric of the original version is the unweighted mean, over the questions, of the pass rate across multiple runs of each question (103 questions); Pro judges a pass by a deterministic target and a tolerance. The passed value from the public grader is the authoritative conclusion, and score is only a diagnostic summary of fields and does not take the place of pass.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 ) ; [3](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**评分方式**：Deterministic binary scoring, using targets that can be recovered from visible evidence and per-field calibration tolerances. This is not an LLM assigning preference scores from a long rubric. The public package follows ground_truth and grader.config in eval_config.json.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**提示与运行设置**：Pro provides an isolated workspace, a short scientific background, the target estimand, and data files. The tool stack includes scientific computing in Python and basic genomics packages; a public reproduction is given only the Agent task and data_files, and the answers and the grader remain on the runner. The reasoning level of the model and the Pro harness must be kept on separate tracks.

Sources: [1](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 ) ; [2](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**官方复现入口**：https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/reference_grader.py (Python>=3.10; reads the question eval_config.json and eval_answer.json)

Sources: [1](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )

**可比性警告**：The 103 questions of GeneBench, the 129 questions of Pro, Pro v13, the 10 public questions, and the proposed 50 questions for AA cannot be ranked together; the GPT Pro harness is also not the same as the ordinary reasoning level of the same name. The figures 21.6 and 20.4 on the Rosalind update page differ from the historical configuration in the paper, and the context of each source is kept.

Sources: [1](https://cdn.openai.com/pdf/6dc7175d-d9e7-4b8d-96b8-48fe5798cd5b/oai_genebench_benchmark.pdf) (accessed 2026-11-07 ) ; [2](https://openai.com/index/introducing-genebench-pro/) (accessed 2026-11-07 ) ; [3](https://openai.com/index/gpt-6-astra/) (accessed 2026-11-07 ) ; [4](https://huggingface.co/datasets/openai/genebench-pro-public-package/blob/main/README.md) (accessed 2026-11-07 )
