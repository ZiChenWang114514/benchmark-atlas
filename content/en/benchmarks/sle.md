## Design goals

**Capabilities tested**：Separately scores hypothesis discovery, protocol planning, scientific computing, scientific software operation, and experiment observation, plus end-to-end research that is still being expanded. Wet-lab execution targets real laboratories and instrument readouts and is unscored in v1.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Gap in prior benchmarks**：The project argues that a model may write a plausible answer yet fail to run a simulation or operate scientific software, so capability splits and independently checkable artifacts are needed beyond final text answers.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

## Construction

**Question sources**：Tasks draw on real laboratory materials, research code, and specialist software across nine disciplines: statistics, physics, astronomy, chemistry, earth science, biology, engineering, materials science, and medicine.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Author background**：Written and reviewed by PhD students and postdoctoral researchers from 34 institutions in five countries, participating in a personal capacity.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Review process**：Domain researchers write and review tasks. Final artifacts for end-to-end tasks are judged by independent checks sealed in advance and withheld from the agent.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Quality control**：Each experiment combines an agent profile, a runtime environment, and a task with declared outputs; separate verifiers grade artifacts and retain per-task results and traces.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Decontamination**：Unverified

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

## Data format

**Size**：v1 has 113 public tasks: hypothesis discovery 5, protocol planning 40, scientific computing 23, scientific software operation 14, experiment observation 30, and end-to-end research 1. Wet-lab execution is in construction with zero released tasks.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Question types**：Agents use tools in Docker or scientific desktop environments and submit checkable artifacts; hypothesis discovery uses the DiscoveryRSI harness.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Modalities**：Text instructions, research code, specialist software project files, laboratory recordings, and protocols.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Languages**：The website and documentation are primarily in English.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Difficulty**：The official composite board still shows a clear gap for current models; listed models score 0 on the end-to-end research task.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Public and hidden split**：The 113 public tasks and agent inputs are downloadable; reference solutions and hidden evaluation data require a separate Hugging Face access request with manual approval.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

## Evaluation

**Metrics**：Capabilities use pass rate, mean score, or inspire rate; the composite is a six-assessment score on a 0-100 scale.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Scoring**：Independent verifiers grade submitted artifacts. End-to-end research is included in the composite but currently scores 0 for listed models. Wet-lab execution is unscored in v1.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Prompt settings**：The board uses pinned Codex or Claude Code profiles; hypothesis discovery uses DiscoveryRSI. The board is dated 2026-11-09 and covers nine models.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Official scripts**：Official docs describe evaluation via task lists and Docker environments; public downloads opened on 2026-11-06.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)

**Comparability note**：Scores come from the project's public board, not an independent third-party retest. Gemini 4 Argon has no composite score because hypothesis discovery is pending.

Sources: [1](https://sciences-last-exam.org/) [2](https://aitonomy.org/projects/sle) [3](https://sciences-last-exam.org/docs) [4](https://github.com/Gen-Verse/Science-Last-Exam) (accessed 2026-11-10)
