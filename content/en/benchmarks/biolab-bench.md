# BioLab Bench

An expert-grounded evaluation framework for autonomous wet-lab work with 294 synthetic- and molecular-biology tasks; companion ProtoPilot reports about 96.6% protocol-to-code gate pass rate.

## Design goals

**Capabilities tested**：Evaluates whether agents can carry experimental intent through protocol design, device-agnostic and device-specific SOPs, machine code, execution gates, and wet-lab feedback revision on automated platforms.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Gap in prior benchmarks**：Plausible protocol text is not enough; evaluation should test whether biological intent remains intact in executable, testable, and revisable workflows.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

## Construction

**Question sources**：294 synthetic-biology and molecular-biology tasks derived from 98 gold-standard protocols, with wet-lab expert rubrics, device-level validity gates, and real experimental tests.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

## Data format

**Size**：294 tasks from 98 gold-standard protocols; stratified L1–L3 difficulty per the press release.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Question types**：Full-chain evaluation from intent interpretation through protocol, SOP, machine code, execution gates, and wet-lab feedback revision.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Modalities**：Natural-language intent, protocol text, SOPs, device SDK code, and experimental readouts.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Languages**：Paper and press materials are primarily in English.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Difficulty**：ProtoPilot scores about 52.38% on ProtocolQA (human expert about 54%); protocol-to-code gate pass about 96.6% and Opentrons pass about 88.2% versus about 32.4% for OpenTrons-AI.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)

**Public and hidden split**：Paper and press release disclose the framework and headline numbers; a fully public dataset link is pending verification.

Sources: [1](https://arxiv.org/abs/2606.31763) [2](https://www.prnewswire.com/news-releases/mgi-tech-and-shanghai-ai-laboratory-unveil-protopilot-and-biolab-bench-pioneering-physical-ai-for-life-sciences-302818081.html) [3](https://arxiv.org/pdf/2606.31763) (accessed 2026-11-10)
