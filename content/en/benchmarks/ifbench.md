# IFBench

> Benchmark Constitution, source-by-source in-depth check: 2026-11-08. The collection date does not represent the experiment date; Unverified is not the same as Not disclosed.

IFBench tests generalization to precise instructions with 58 verifiable constraints that have not been seen, rather than renaming IFEval. The original test of 300 items, the AA implementation of 294 questions, 29 classes of training constraints, and 83 verifiers in the software package are four different statistical scopes. This page gives the license of the code and the license of the data separately.

Basis of the reading guide: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-08); [2](https://github.com/allenai/IFBench) (accessed 2026-11-08); [3](https://huggingface.co/datasets/allenai/IFBench_test) (accessed 2026-11-08).

## Design goals

### 测量能力

Generalization to 58 novel output constraints that can be checked by a program and that lie outside the training domain, including count, proportion, word, sentence, format, custom, and copy.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 与既有基准的差异

The 25 constraint types in IFEval may be overfit; IFBench is not an alias for IFEval or a new version of it.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

## Construction

### Question sources

Constraints are designed from manually collected user feedback and core skill requirements, combined with unpublished held-out WildChat prompts.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 出题者背景

Researchers in instruction following and post-training; the specific qualifications of the compatibility annotators are Unverified.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Review process

Each instance is checked manually to confirm that the prompt and the constraints are compatible and can be satisfied at the same time.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Quality control

Python verification functions are written for the constraints; train/test constraint overlap is excluded.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 去污染与泄漏控制

The 58 new test constraints are kept separate from the 29 IFTrain training constraints, and the original WildChat prompts are held out; leakage prevention is still required after release.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

## Data format

### 规模与统计口径

The original IFBench has 300 prompts, each containing 1 or 2 constraints; AA evaluates 294 questions.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Question types

Open-text output, a single-turn task plus constraints; in multiple turns, the original task is answered first and then rewritten under the constraints.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Modalities

```json
[
  "文本"
]
```

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Languages

The test prompts are mainly in English and include constraints that require a specific output, such as Japanese or Russian; a constraint on the language of the output must not be mistaken for a statement that every question is in a single language.

Sources: [1](https://huggingface.co/datasets/allenai/IFBench_test) (accessed 2026-11-08).

### Difficulty

Intended to test generalization to unseen constraints; ability is not inferred from the IFEval score.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### Public and hidden splits

IFBench evaluates 300 prompts; the 29 constraints in IFTrain and its training prompts are separate material and are not folded into the scale of the test.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

## Evaluation

### Metrics

strict/loose accuracy; the paper reports prompt-level loose accuracy, and AA uses rule-based scoring at pass@1.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 评分规则

strict verifies directly; loose allows the first and last lines, and some font markers, to be removed before the check. The question-level convention and the constraint-level convention must not be mixed.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 提示、采样与工具设置

The original paper usually uses temperature 0; for reasoning models, tokens are adjusted and the chain of thought is removed; DeepSeek R1 uses 0.6/top_p .95, and o3 uses temperature 1.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 官方脚本

The current ifbench package can be installed with pip, with namespaces such as ifbench.instructions and instructions_registry. The wheel contains test JSONL, accessed via ifbench.data_path. The primary metric in the original paper is prompt-level loose accuracy.

Sources: [1](https://github.com/allenai/IFBench/blob/main/README.md) (accessed 2026-11-08).

### 可比性警告

AA's 294 questions × 5 runs differ from the original 300 prompts; the differences between single-turn and multi-turn, and between strict and loose, must be retained.

Sources: [1](https://arxiv.org/abs/2507.02833) (accessed 2026-11-07).

### 饱和度与证据边界

The AA set of 294 questions peaks at 83.3%; on the 300-question prompt-loose track of the original paper, IF-RLVR qwen2.5 7b is 53.7%. Different question sets and implementations cannot be used directly for a unified conclusion about saturation.

Sources: [1](https://artificialanalysis.ai/evaluations/ifbench) (accessed 2026-11-08 ) ; [2](https://arxiv.org/pdf/2507.02833) (accessed 2026-11-08).

### 污染与已知问题

The current HF page shows associated entries of models trained or fine-tuned on IFBench_test, which demonstrates a visible risk that the public test set has been used for training. This is not an accusation that any particular model on a leaderboard has leaked. The benchmark also measures only verifiable constraints of form, and it does not guarantee the quality of the semantic answer.

Sources: [1](https://huggingface.co/datasets/allenai/IFBench_test) (accessed 2026-11-08 ) ; [2](https://arxiv.org/pdf/2507.02833) (accessed 2026-11-08).

### 相关与衍生基准

Distinct from the included ifeval: IFBench tests generalization to out-of-domain constraints and cannot be treated as a new name for IFEval.

> Editorial note on deduplication; the same benchmark subset, metric, or version is not counted more than once.

Sources: [1](https://github.com/allenai/IFBench) (accessed 2026-11-07).
