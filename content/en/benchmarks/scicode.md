# SciCode

> Verification date: 2026-11-08. The access date is not the publication date or the run date; a field that cannot be confirmed remains Unverified.

SciCode splits the everyday research scripts of scientists into dependent Python subproblems, and it examines whether scientific concepts, reasoning, and code can together form an executable solution. Success on the main problem and success on a single subproblem are different metrics; whether background knowledge and the preceding gold answers are provided changes the task. The official historical leaderboard and the independent AA implementation must be read on separate tracks.

Guide source: [Official materials](https://scicode-bench.github.io/) (accessed 2026-11-08); specific facts and historical access dates are given in the individual fields.

## Construction

### 题目或数据来源

Researchers choose questions from everyday research scripts and papers and split main questions into subquestions; three review rounds cover same-field review, cross-field review, and model-assisted review, and standard answers and tests are provided.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### 出题背景

Researchers and AI researchers from 16 natural-science subfields compile scientific code tasks from actual research workflows.

Sources: [1](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， )

### Review process

Researchers choose questions from everyday research scripts and papers and split main questions into subquestions; three review rounds cover same-field review, cross-field review, and model-assisted review, and standard answers and tests are provided.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### Quality control

At least two scientists in the same field cross-check the problem statement, the solution, and the tests of each question; one scientist from another field checks clarity and whether the constants are complete; after GPT-4 attempts a solution, scientists analyze the errors and revise the numerical tests, in order to reduce false positives.

Sources: [1](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， )

### 去污染措施

The paper states that the selected problems have zero overlap with public datasets; this is not an independent contamination audit of the training set of every model.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

## Data format

### Size

80 main questions and 338 subquestions; the development set has 15 main questions and 50 subquestions, and the test set has 65 main questions and 288 subquestions.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### Question types

Generation of Python functions and of research code; a main problem is composed of several dependent subproblems, covering numerical methods, simulation of systems, and scientific computing.

Sources: [1](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， )

### Modalities

Text task descriptions and Python code

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### Languages

English problem statements and Python code; the official HF data card has language=en.

Sources: [1](https://huggingface.co/datasets/SciCode1/SciCode/raw/main/README.md) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， )

### Difficulty

Research-level questions, not textbook examination questions; the median number of subquestions per main question is 3, and the maximum is 15. The questions cover five disciplines and 16 subfields; difficulty depends on whether background knowledge and earlier answers are available.

Sources: [1](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， )

### 数据划分

Development: 15 main questions and 50 sub-questions; test: 65 main questions and 288 sub-questions.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

## Evaluation

### Metrics

Tests are run and pass@1 is reported; main problems must be distinguished from subproblems, the presence of background knowledge from its absence, and prior answers that are the standard from those that are generated.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### Scoring

Tests are run and pass@1 is reported; main problems must be distinguished from subproblems, the presence of background knowledge from its absence, and prior answers that are the standard from those that are generated.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )

### 提示与运行设置

The path that is currently recommended is inspect_ai, and the example in the README uses temperature=0; the older two-stage method of gencode/unittest has been deprecated. A setting that supplies background information, and a setting that supplies a preceding solution, must be recorded separately.

Sources: [1](https://github.com/scicode-bench/SciCode) (accessed 2026-11-07， )

### 评测脚本

eval/inspect_ai/scicode.py is recommended. The older eval/scripts/gencode.py and test_generated_code.py are marked deprecated.

Sources: [1](https://github.com/scicode-bench/SciCode) (accessed 2026-11-07， )

### 可比性提醒

Different data versions, subsets, prompts, tool permissions, and model snapshots must not be mixed in a direct comparison; scores in historical papers do not represent the current SOTA.

Sources: [1](https://arxiv.org/abs/2407.13168) (accessed 2026-11-08， ) ; [2](https://arxiv.org/pdf/2407.13168) (accessed 2026-11-08， ) ; [3](https://scicode-bench.github.io/) (accessed 2026-11-08， ) ; [4](https://artificialanalysis.ai/evaluations/scicode) (accessed 2026-11-07， )
