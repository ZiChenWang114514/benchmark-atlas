# ChemArgus

A multimodal diagnostic benchmark for competition-level, lab-grade chemistry reasoning, with 153 public problems and 600 public subquestions, using three protocols to locate where a reasoning chain breaks.

## Design goals

**Capabilities tested**：Tests competition-level, open-ended chemistry reasoning and multimodal understanding, and uses point-wise partial credit to locate whether a reasoning chain fails in integration, error propagation or local reasoning

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Gap in prior benchmarks**：The paper argues that current frontier chemistry benchmarks still score answer endpoints alone, which conflates memorized facts with stepwise derivation, treats visual and textual inputs as interchangeable, and confounds long-horizon planning with stepwise execution, so they cannot say where a reasoning chain breaks

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

## Construction

**Question sources**：Problems are built from first principles using chemistry competition material, textbooks and research papers, then normalized into structured units with a shared header, a chain of subquestions, model-visible images, controlled text descriptions and rubrics

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Author background**：Released by CosmosMind; the paper does not state the authors' institutional affiliations

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Review process**：Candidate problems pass expert review, adversarial model probing and student pilots; only those that satisfy chemical correctness, scorability and meaningful discrimination enter the final set

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Quality control**：Construction uses a four-step refinement loop and three quality-gating stages. Scoring is dual-track: structures, SMILES, equations and computed values first receive deterministic chemistry-equivalence checks, while flexible mechanistic and experimental answers are graded point by point by an independent language-model judge; low-confidence and boundary cases go to human review, and judge-human agreement is spot-checked

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Decontamination**：Rubric-private images never enter any model input. The official materials state that the private set is never published. The official board also treats access control as part of the measurement design. Rubric fields are stripped from the public test set

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

## Data format

**Size**：The official repository reports the public partitions as: a development set of 48 problems, 209 subquestions, 676 marks and 350 images (rubrics included); a test set of 105 problems, 391 subquestions, 1,271 marks and 173 images (rubrics stripped); public totals of 153 problems, 600 subquestions, 1,947 marks and 523 images. A private set of 38 problems is never published. The official leaderboard summarizes 23 exam papers, 191 problems, 820 scorable subquestions and 2,582 rubric points, which matches the public totals plus the private set. Problems are assigned so that the number of model-visible images is roughly equal across the three partitions (about 164 images on average) while keeping the 25%/55%/20% problem ratio exact

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Question types**：Open-ended, competition-level chemistry problems formed as a shared header plus an ordered chain of subquestions, covering areas such as electrochemistry, multi-step organic synthesis and industrial chemistry; answers include structures, SMILES, equations, computed values, and mechanistic or experimental explanations

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Modalities**：Real images paired with controlled text descriptions; evaluation also uses a text-only mode and a text-plus-external-image-reader mode. Rubric images are never shown to the answering model

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Languages**：English

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Difficulty**：In all 25 reported runs, unassisted whole-problem solving is the lowest of the three protocols. In paper Table 2, multimodal full-problem scores range from 23.2% to 53.8%, and text-only full-problem scores range from 23.5% to 61.5%. The official board states that some leading scores are not based on the full problem set and should not be read as complete-set results

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Public and hidden split**：A public development set of 48 problems with rubrics, a public test set of 105 problems with rubrics stripped, and an unpublished private set of 38 problems, in a 25%/55%/20% problem ratio

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

## Evaluation

**Metrics**：Normalized rubric score, the share of rubric points earned, reported as a percentage. The three protocols are full problem, sequential carry and oracle scaffolded; because they share one scoring unit, gaps between them are used to isolate integration burden, error propagation and local reasoning

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Scoring**：Each subquestion is graded point by point with partial credit. Formal answers pass deterministic chemistry-equivalence checks before the judge session; flexible answers are graded by an independent judge against each rubric point. The paper states that the judge model is GPT-5.6-Sol and that human spot-checks agree highly enough to report the judge numbers alone. Every grading interaction is archived

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Prompt settings**：Zero prompting: only the problem content required by the protocol is provided, with no few-shot examples, reasoning instructions, tools or web search. All models except Claude Opus 5 run in the open-source Pi agent harness; Claude Opus 5 runs in the Claude Code harness. Models use default settings with no task-specific fine-tuning. In the text-plus-reader setting, a text model is paired with the Qwen3-VL image reader and decides when to invoke it

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Official scripts**：https://github.com/CosmosMind-ai/ChemArgus

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)

**Comparability note**：The official board states that each percentage is computed on that run's own scored problem set, so denominators differ across runs. Claude Opus 5 runs are described as a provisional prefix of 39 to 103 points after high-scoring problem removal under scheme A on 2026-09-21, pending completion of the full set. Gemini 3.8 Flash and Grok 4.6 runs sit on a 12-paper, 1,136-point subset of the evaluation set. Leading scores in the table should therefore not be treated as a direct ranking on one complete set

Sources: [1](https://arxiv.org/abs/2610.20012) [2](https://www.cosmosmind.ai/leaderboard/chemargus) [3](https://github.com/CosmosMind-ai/ChemArgus) (accessed 2026-11-11)
