# CritPt v2

> Benchmark Constitution, in-depth verification snapshot 2026-11-07. Unverified is not the same as Not disclosed; the collection date is not the leaderboard update time.

CritPt turns original physics research questions into compound challenges that a machine can verify. The 71 challenges in the original paper include one example, and the deployed test set has 70 questions. AA's 40-question Hard Subset does not constitute a separate benchmark. Paper v4, software deployment v2, and the HF storage split name train are three different concepts. In particular, the HF train label cannot be read as authorization to train.

Basis of the guide: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07); [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

## Design goals

**测量能力**：Comprehensive reasoning on unpublished research-level physics problems; verifiable answers are derived from theoretical, experimental, or computational conditions.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**针对的不足**：Textbook and contest questions poorly represent open-ended long-chain reasoning in original research.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

## Construction

**材料来源**：Original work by physics experts, based on their own research; the 71 challenges in the original paper include 1 example, and there are also 190 checkpoints.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**出题背景**：More than 50 physics researchers from 30 institutions, including doctoral students, postdoctoral researchers, and professors (original-version definition).

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**审核**：Multiple rounds of revision by experts and coordinators, peer review in nearby fields, review of technical derivations, and editing of scientific writing.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**质控**：Reference answers must be machine-verifiable, and physics-relevant tolerances must be set for numeric, symbolic, and function outputs.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**去污染边界**：Original unpublished questions and answers resistant to guessing, with solutions to the test questions kept confidential; this cannot, on that basis, guarantee a complete absence of contamination.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

## Data format

**规模与统计口径**：The full v2 set has 70 questions; the AA Hard Subset is 40 of them and is not counted as a separate benchmark.

Sources: [1](https://artificialanalysis.ai/methodology/intelligence-benchmarking) (accessed 2026-11-07)

**任务形式**：Open-ended question answering; the answers are numeric values, symbolic expressions, and executable functions.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**模态**：文本；数学表达式；Python functions

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**语言**：The public stems and the technical descriptions are in English; answers may be mathematical expressions and Python code or functions.

Sources: [1](https://raw.githubusercontent.com/CritPt-Benchmark/CritPt/main/README.md) (accessed 2026-11-07); [2](https://huggingface.co/datasets/CritPt-Benchmark/CritPt/raw/main/README.md) (accessed 2026-11-07); [3](https://arxiv.org/pdf/2509.26574) (accessed 2026-11-07)

**难度**：A research-level challenge. The official card places it at the complexity of a complete research project for an early-stage doctoral student in physics; the AA Hard Subset is 40 of those questions, and it cannot be presented as another research-level question bank of 70 questions.

Sources: [1](https://raw.githubusercontent.com/CritPt-Benchmark/CritPt/main/README.md) (accessed 2026-11-07); [2](https://huggingface.co/datasets/CritPt-Benchmark/CritPt/raw/main/README.md) (accessed 2026-11-07); [3](https://arxiv.org/pdf/2509.26574) (accessed 2026-11-07)

**公开/保留划分**：HF provides 70 questions. The stored split is named train, but the card explicitly calls it a test set and forbids training; 1 example is also public. Public questions do not mean that the standard answers, or the tests scored by the server, are public.

Sources: [1](https://raw.githubusercontent.com/CritPt-Benchmark/CritPt/main/README.md) (accessed 2026-11-07); [2](https://huggingface.co/datasets/CritPt-Benchmark/CritPt/raw/main/README.md) (accessed 2026-11-07); [3](https://arxiv.org/pdf/2509.26574) (accessed 2026-11-07)

## Evaluation

**指标**：pass@1 on the full set of 70 questions; the index uses pass@1 on the Hard Subset of 40 questions. Both are averaged over 5 runs.

Sources: [1](https://artificialanalysis.ai/methodology/intelligence-benchmarking) (accessed 2026-11-07)

**评分**：The final answer is verified against an expert gold standard, and a composite answer must be correct in every part; the original paper includes numerical tolerance, SymPy equivalence, and function tests.

Sources: [1](https://arxiv.org/abs/2509.26574) (accessed 2026-11-07)

**提示与运行设定**：AA: an offline Linux sandbox provides code execution; the official scoring server is used, with 5 independent runs.

Sources: [1](https://artificialanalysis.ai/methodology/intelligence-benchmarking) (accessed 2026-11-07)

**脚本/运行入口**：https://github.com/CritPt-Benchmark/CritPt; responses are generated locally and then sent to the AA partner scoring server. Each batch must contain all 70 questions, and the README lists at most 10 submissions per account in 24 hours. The HF card still links the old name CritPt_Eval, and the current official repository is preferred.

Sources: [1](https://raw.githubusercontent.com/CritPt-Benchmark/CritPt/main/README.md) (accessed 2026-11-07); [2](https://huggingface.co/datasets/CritPt-Benchmark/CritPt/raw/main/README.md) (accessed 2026-11-07); [3](https://arxiv.org/pdf/2509.26574) (accessed 2026-11-07)

**可比性**：Results from v1 without an agent, v2 results on all 70 questions, and Hard Subset results on 40 questions cannot be mixed; both the tools and the question set change the score.

Sources: [1](https://artificialanalysis.ai/methodology/intelligence-benchmarking) (accessed 2026-11-07)
