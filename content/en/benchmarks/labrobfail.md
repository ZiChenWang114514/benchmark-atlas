# LabRobFail

A robotic failure-analysis benchmark for chemical self-driving labs with 20,000+ trajectories and six evaluation dimensions; LabRobFail-VLM reaches about 90.83% failure-detection accuracy on seen environments.

## Design goals

**Capabilities tested**：Evaluates robotic failure detection, temporal localization, severity assessment, classification, and actionable correction across perception, grasping, motion, logic, and safety failures in chemical labs.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Gap in prior benchmarks**：Chemical failures can be irreversible and hazardous; prior simulators emphasize successful execution and lack fine-grained failure injection and multi-dimensional protocols.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

## Data format

**Size**：Over 20,000 operation trajectories; 70+ task scenarios; five failure categories and 11 fine-grained types; six evaluation dimensions.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Question types**：Task understanding, failure detection, temporal localization, severity assessment, failure classification, and actionable correction.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Modalities**：High-fidelity simulation trajectories, vision and control signals, and structured diagnostic outputs.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Languages**：Paper is primarily in English.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Difficulty**：General-purpose VLMs lag substantially; specialized LabRobFail-VLM reaches about 90.83% failure-detection and 77.21% temporal-localization accuracy on seen environments.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Public and hidden split**：GitHub repository is public; full dataset release details need further verification.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

## Evaluation

**Metrics**：Failure-detection accuracy, temporal-localization accuracy, and downstream task success-rate gains.

Sources: [1](https://arxiv.org/abs/2607.23704) [2](https://github.com/Su-ISE-2001/LabRobFail) [3](https://arxiv.org/pdf/2607.23704) (accessed 2026-11-10)

**Scoring**：Six capabilities are scored separately; authors also report about 4–16 percentage-point gains when used as a real-time supervisor.
