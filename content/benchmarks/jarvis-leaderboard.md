# JARVIS-Leaderboard

> Benchmark Constitution｜逐源深度核查：2026-11-08（KST / Asia/Seoul）。采集日期不代表实验日期；待核实不等于未公开。

JARVIS-Leaderboard是材料方法的可复现多任务平台，不是单一LLM题库。本轮从首页示例深入到三个材料性质子榜，按各自MAE及物理单位提取精确成绩；不同性质、参考DFT及实验条件之间不存在统一总冠军。

导读依据：[1](https://arxiv.org/abs/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

## 设计目标

### 测量能力

在统一平台记录多模态材料设计方法的性能及可复现元数据。

来源：[1](https://arxiv.org/abs/2306.11688)（访问 2026-11-07）；[2](https://arxiv.org/pdf/2306.11688)（访问 2026-11-07）；[3](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。

### 与既有基准的差异

材料设计方法往往将代码、数据和结果分散在GitHub、Zenodo、Figshare等处，且缺少共同划分及计算环境；平台把参考数据、预测、执行脚本与硬软件元数据连接起来，覆盖AI之外的ES、FF、QC及实验。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

## 构建方式

### 题目来源

社区提交数据、代码和方法元数据；覆盖 AI、电子结构、力场、量子计算及实验等类别。

来源：[1](https://arxiv.org/abs/2306.11688)（访问 2026-11-07）；[2](https://arxiv.org/pdf/2306.11688)（访问 2026-11-07）；[3](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。

### 出题者背景

NIST材料计算与数据研究人员及来自电子结构、机器学习力场、量子计算、实验等社区的贡献者；提交者资质不自动等于每项预测已被独立复现。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 审核流程

提交者准备预测csv.zip、metadata.json及可选run.sh/环境文件，经最小sanity checks、GitHub Actions后由NIST管理员审核并合入榜单。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）。

### 质量控制

最低自动检查包括通过 GitHub Actions 重建榜单和安装软件；记录预测、软件、硬件和仪器背景以支持复现。

来源：[1](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。

### 去污染与泄漏控制

采用固定划分以避免训练/测试混淆；同库ID及目标公开不构成LLM式防训练泄漏证明，预训练力场与同集训练模型必须按具体任务区分。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）。

## 数据形式

### 规模与统计口径

本次官网快照322个benchmark、2087项贡献、8,752,827个datapoints；这些是平台聚合量，不是单一任务题量。

来源：[1](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。

### 题型

按任务输出标量性质、分类标签、多值光谱/力、生成结构或文本等；不是一道统一的自然语言问答测试。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 模态

```json
[
  "化学式与原子结构",
  "材料性质数值/力/光谱",
  "STEM图像",
  "论文文本",
  "实验数据",
  "Hamiltonian与量子结果"
]
```

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 语言

平台说明与论文为英语；输入还包括结构、化学式、数值、图像和代码，不能用单一自然语言标签覆盖所有子任务。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 难度

难度按具体材料性质与参考方法而异；误差单位、测试样本及基线不同，不设可跨任务比较的统一easy/hard或总冠军。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）。

### 公开与隐藏划分

AI任务用预定义train/validation/test ID和目标JSON，固定随机划分；ES、FF、QC、实验通常只有参考test。平台展示test性能，底层数据经JARVIS-Tools及有版本DOI的Figshare存放。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）。

## 评测方法

### 指标

按具体任务报告 MAE、ACC 或 MULTIMAE 等；不同任务不拼成同一排名。

来源：[1](https://arxiv.org/abs/2306.11688)（访问 2026-11-07）；[2](https://arxiv.org/pdf/2306.11688)（访问 2026-11-07）；[3](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。

### 评分规则

将csv.zip预测ID与相应benchmark JSON的test ID对齐，按该任务MAE、ACC或MULTIMAE计算；MAE需连同物理单位、参照DFT/实验和样本划分报告。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 提示、采样与工具设置

不适用统一LLM提示：以各贡献run.sh、软件版本、硬件和任务配置为准；TextGen等语言任务另查对应子榜。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 官方脚本

jarvis_populate_data.py生成参考划分；jarvis_upload.py协助提交；各贡献run.sh用于复现；GitHub Actions检查榜单重建和安装。

来源：[1](https://arxiv.org/pdf/2306.11688)（访问 2026-11-08）；[2](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-08）。

### 可比性警告

不同数据版本、子集、提示、工具权限及模型快照不得直接混比；历史论文分数不代表当前SOTA。

来源：[1](https://arxiv.org/abs/2306.11688)（访问 2026-11-07）；[2](https://arxiv.org/pdf/2306.11688)（访问 2026-11-07）；[3](https://pages.nist.gov/jarvis_leaderboard/)（访问 2026-11-07）。
