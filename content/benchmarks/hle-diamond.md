# HLE-Diamond

> Benchmark Constitution｜逐源深度核查：2026-11-08。采集日期不代表实验日期；待核实不等于未公开。

HLE-Diamond是2026-09-22发布的1000题清洗子集，知识与推理各500题，而不是原HLE的另一种写法。官方high闭卷、web+code及AA独立评测是三条不同协议；本页不把工具带来的高分混入闭卷排序。

导读依据：[1](https://arxiv.org/abs/2501.14249)（访问 2026-11-08）；[2](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-08）；[3](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-08）。

## 设计目标

### 测量能力

闭卷专家知识与跨学科推理；包含图像题，分别报告知识与推理分区。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）。

### 与既有基准的差异

针对原HLE问题质量，经研究社区反馈清洗与精炼，建立可持续比较的新版子集。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）。

## 构建方式

### 题目来源

从原HLE题目集合清洗、精炼而来。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）。

### 出题者背景

沿用HLE全球领域专家题目，经一年清洗；发布文章感谢题目贡献者和HLE-Rolling研究社区，不将原HLE所有作者自动算作Diamond独立作者。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-08）；[2](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-08）。

### 审核流程

历时一年的清洗与精炼，结合研究社区及HLE-Rolling反馈。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）。

### 质量控制

知识与推理各500题；不把原HLE总分直接当Diamond分数。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）。

### 去污染与泄漏控制

数据卡加入canary字符串供训练数据过滤，并明确要求基准数据不进入训练语料。

来源：[1](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-07）。

## 数据形式

### 规模与统计口径

1,000题：500推理、500知识。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）；[2](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-07）；[3](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 题型

沿用HLE字段格式；AA以开放答案与等价检查裁判评分。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）；[2](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-07）；[3](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 模态

```json
[
  "文本"
  "图像（272题）"
]
```

来源：[1](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 语言

公开数据卡说明所有列沿用HLE格式；AA使用官方英文HLE系统提示。完整逐题语种统计待核实，不能据此声称全部单语。

来源：[1](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-08）；[2](https://artificialanalysis.ai/evaluations/hle-diamond)（访问 2026-11-08）。

### 难度

专家级知识与推理各500题；官方high无工具Astra在reasoning得74.2%、knowledge得45.6%，两个分区不能简单解释为同一种难度等级。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-08）。

### 公开与隐藏划分

公开test split；partition列区分reasoning与knowledge。

来源：[1](https://lastexam.ai/blog/hle-diamond)（访问 2026-11-07）；[2](https://huggingface.co/datasets/cais/hle-diamond)（访问 2026-11-07）；[3](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

## 评测方法

### 指标

pass@1 / 准确率；另报reasoning和knowledge。

来源：[1](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 评分规则

AA遵循官方HLE裁判提示与格式，GPT-5.6 Luna (medium)判答案正确性。

来源：[1](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 提示、采样与工具设置

```json
{
  "AA": "1000题各1次、无工具；官方HLE系统提示；GPT-5.6 Luna (medium)裁判；视觉模型收图，非视觉模型仅收文字但仍按全部题计分。"
  "official_tools": "web+code工具轨使用Python 3.11.16和固定依赖；代码sandbox不直接联网，仅通过web_search/web_fetch取外部信息；官方blocklist过滤问题/答案泄漏；按提供商agent harness运行。"
}
```

来源：[1](https://artificialanalysis.ai/evaluations/hle-diamond)（访问 2026-11-08）；[2](https://github.com/centerforaisafety/hle/blob/main/docs/evaluation-with-tools.md)（访问 2026-11-08）。

### 官方脚本

https://github.com/centerforaisafety/hle

来源：[1](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。

### 可比性警告

官方文章high推理、max推理及工具轨不同；AA使用自有裁判实现。原HLE的2,158纯文本题结果不可与Diamond 1,000题直接比较。

来源：[1](https://artificialanalysis.ai/methodology/intelligence-benchmarking)（访问 2026-11-07）。
