# Remote Labor Index

> 第2轮深度核验：2026-11-08（KST / Asia/Seoul）。访问日不等于发布日期或实验运行日；未知保留，不推定“未公开”。

Remote Labor Index用真实自由职业项目与人类交付物评估端到端远程工作。240个项目中230个用于私有定量评估，10个公开供定性检查；人工评审决定产物是否达到合理客户的验收标准。Automation Rate不是全经济就业替代率，公开评审平台也不是可自动复现私有总榜的评分器。

编辑状态：官方存在性已核验；字段级研究快照；note: trending: A

## 3. 设计目标

### 目标能力

端到端完成有真实经济价值、客户可接受的远程自由职业项目。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 相对既有评测的缺口

从孤立技能和研究题转向真实交易产生的专业交付物，直接与人类标准比较。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

## 4. 构建方式

### 题目与标签来源

从Upwork 358名经验证自由职业者收集550初始项目，筛选至240，覆盖23个领域。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 出题/标注背景

经验丰富的自由职业专业人士。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 审核流程

按完整性、可复现性、专业质量筛选；人工受训专家比较交付物。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 质量控制

删除个人信息或以合成信息替换；3名独立评审多数票，官网报告Automation Rate一致率94.4%。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 去污染与隔离

230私有项目参与定量评测；10公开项目只供定性分析。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

## 6. 评测方法

### 指标

Automation Rate主指标；Elo（人类锚定1000）、Dollars Earned、Cost Savings辅指标。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 判分

人工比较AI与人类交付物，1失败、2达标、3超标，2或3算自动化成功；Elo另做模型间成对质量比较。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 提示/推理设置

CLI OpenHands或computer-use环境，统一prompt与多媒体工具；每任务最大生成预算30美元；榜单报告每Agent最佳环境。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）

### 官方实现

https://github.com/centerforaisafety/rli_evaluation_platform；这是多模态交付物人工比较平台，不是可自动复现230题总榜的评分器。README提供10公开任务及样例AI交付物。

[1](https://raw.githubusercontent.com/centerforaisafety/rli_evaluation_platform/main/README.md)（访问 2026-11-08）；[2](https://huggingface.co/datasets/cais/rli-public-set/raw/main/README.md)（访问 2026-11-08）

### 可比性边界

只衡量所采样远程项目，不代表整个经济劳动可替代率；排除了实体劳动、直接客户交互与长期验收。首发2.5%为历史结果，不替代当前榜。

[1](https://labs.scale.com/leaderboard/rli)（访问 2026-11-07）
